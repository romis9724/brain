# Lattice.log

한국어 AI 개발 현장 뉴스 큐레이션 플랫폼. "AI 개발 현장에서 진짜 쓰이는 것만" 필터링을 목표로 함.

- **운영**: Lattice (닉네임, 1인 운영)
- **론칭**: 2026-05-03 (카카오톡 오픈채팅방과 동시 오픈)
- **언어**: 한국어
- **소스**: 150개+ 자동 수집 파이프라인 (HN, arXiv, lobsters, Techmeme, GitHub Trending, X, Reddit 등)

## 뉴스 포맷 (Lattice Live)

하루 3~4회 "📡 Lattice Live" 형식으로 발행:

```
✱ 뉴스 제목
본문 요약 (2~3줄)
왜 지금: 투자·개발 관련성 설명
써먹기: 바이브코더 활용법
출처: 소스명 · URL
```

"왜 지금"과 "써먹기" 포맷이 단순 뉴스 번역이 아닌 실용적 인사이트 제공.
