## 개요

Anthropic이 2026년 6월 출시한 **미토스(Mythos) 클래스** 최초 모델. Claude Opus 4.6 위의 새로운 최상위 계층에 해당한다. 코드팩토리 채널에서 "페이블 5"로도 불림.

## 미토스 클래스 구조

- **미토스 클래스**: Anthropic이 도입한 새 최상위 모델 계층. 군함 클래스처럼 계층 이름 안에 여러 실제 모델(객체)이 존재
- **Fable 5**: 미토스 클래스 중 현재 출시된 첫 번째 모델 (가장 낮은 티어)
- **프로젝트 글래스윙(Glasswing)**: 미토스 클래스 내 다른 프로젝트, 아직 미출시
- 향후 더 높은 미토스 클래스 모델 추가 예정

## 핵심 특성

### vs. Opus 4.6 비교 (코드팩토리 실험 기준)

| 항목 | Fable 5 | Opus 4.6 |
|------|---------|---------|
| 생각 시간 | 14~25분 (50k~100k 토큰) | ~5분 (~23k 토큰) |
| 총 작업 시간 | 53~58분 | 38~49분 |
| 에이전트 방식 | 서브에이전트 5개+ 자동 병렬 | 단독 처리 |
| 보안 이슈 발견 수 | 23건 (저등급까지 상세) | 7건 |
| UI 테마 성향 | 밝은(Light) 테마 선호 | 다크 테마 선호 |
| 시각적 완성도 | 미세하게 높음 (3D 그림자, 기울기) | 충분한 수준 |

### 에이전틱 동작

- 복잡한 작업 시 자동으로 서브에이전트를 여러 개 생성해 병렬 처리
- 일반 Opus보다 훨씬 더 오랫동안 "에이전틱"하게 실행
- 결과의 "깊이(depth)"를 위해 추가 토큰을 적극 소비

## 가격 & 접근

- $200/월 구독 플랜: **2026년 6월 말까지** 포함
- 이후: Extra Usage 과금으로 전환
- 울트라 코드(ultracode) 모드 사용 시 $200 플랜 전체 소모 가능

## 권장 사용 시나리오

- 일반 바이브 코딩, 빠른 프로토타입 → Opus 4.6으로 충분
- 중요 릴리스, 크리티컬 버그픽스, 심층 보안 검사 → Fable 5 활용
