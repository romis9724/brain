# Obsidian Web Clipper

웹 페이지를 마크다운으로 변환해 Obsidian vault에 직접 저장하는 브라우저 확장 프로그램.

## 기능

- 웹 아티클 → 마크다운 원클릭 변환
- 유튜브 영상 → 스크립트(시간 단위) 포함 저장
- 저장 위치: vault 내 지정 폴더 (예: `raw/external/`)

## LLM Wiki에서의 역할

raw/ 폴더로 소스를 빠르게 수집하는 핵심 도구.
[[sources/옵시디언-주식분석-llm위키]]에서 뉴스·유튜브 수집에 활용.

## 이미지 로컬 저장 팁

Obsidian Settings → Files and links → Attachment folder path를 `raw/assets/`로 설정.
Settings → Hotkeys → "Download attachments" 단축키 바인딩 후 클리핑 시 사용.
