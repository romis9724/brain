# 시프티 (Shiftee)

Shiftee Inc.가 운영하는 클라우드 기반 **근태관리·인사관리 SaaS**. 웹·모바일에서 근무일정, 출퇴근 기록, 휴가, 전자결재(승인), 통계를 통합 관리한다.

## 구조

- **회사 생성 → 직원 합류** 모델 (최고관리자가 회사를 만들면 직원이 합류)
- 권한: 최고관리자 / 관리자 / 직원 모드 (모드 전환 가능)
- 단일 계정으로 웹·모바일 공용

## 주요 기능 영역

- **조직/지점·직무** — 부서형(조직) 또는 지역형(지점) 관리 단위
- **근무일정** — 유형·템플릿·패턴, 엑셀 업로드, 간주근로, 연장/휴일/재택 사용 사례
- **출퇴근기록** — 좌표/IP/WiFi 기반 위치 인증, 모바일 단축어 자동화, 누락 알림
- **휴가** — 그룹·유형·발생·잔여 관리
- **전자결재** — 승인 규칙 기반 요청(근무일정/출퇴근/휴가)
- **근로정보** — 소정근로·최대근로 규칙으로 정교한 근태관리

## 데이터 마이그레이션 (도입 강점)

- 기존 HR 솔루션·ERP 데이터를 **엑셀 양식** 또는 **Open API**로 이전 (별도 개발 불필요)
- 업로드 시 오류 셀을 붉은색 표시 → 사유 확인 후 수정
- 직원·근로정보·조직·근무일정·휴가·출퇴근·승인규칙 등 폭넓은 항목 지원
