# 혼자 AI로 만든 SaaS, 월 2,000만 원 찍었습니다

[[wiki/entities/people/하조은]] 채널의 [[wiki/entities/people/민상기]] 인터뷰. 초등교사 14년 → 개발자 1년 → AI 창업가. Claude Code로 혼자 학교 상담실 SaaS "위노트(WeeNote)"를 만들어 전국 200개 학교, 월 매출 2,000만 원을 달성한 과정을 담은 영상.

## 핵심 포인트

- **오버 엔지니어링 2번 실패**: v1은 클라우드 기반 + 얼리어답터 요구사항 → 대중 거부. 로컬 앱으로 재구축 후 PMF 확보
- **PMF 판별법**: "런칭하자마자 결제가 들어오면 PMF" — 실제로 런칭 당일 결제 발생
- **기술 매몰 경계**: 제품명에 'AI' 추가했다가 심리상담 분야 고객 이탈. "나는 기술에 매몰된 개발자였구나" 자각
- **해자는 커뮤니티**: 기능은 한 달 만에 복제 가능. 1,000명 학교 상담교사 커뮤니티 + 멘토 20명이 진짜 해자
- **최고의 QA는 고객**: 테스트 없이 배포 → 버그 리포트 → 30분~1시간 내 수정 → 즉시 피드백 → 팬 형성
- **24시간 고객 응대**: 새벽 1시에도 직접 응답 → "AI 상담사인가요?" 질문 받을 정도로 팬 만들기

## 제품 소개: 위노트(WeeNote)

- **타겟**: 학교 위클래스(상담실) 상담교사
- **핵심 가치**: 상담일지 → 월간 통계 → 나이스 업로드 자동화. 2~3시간 → 10분
- **차별점**: 로컬 데스크탑 앱 (클라우드 거부감 있는 상담 분야 특성 반영), 데이터가 선생님 PC에만 저장
- **가격**: 베이직 30만원/년 · 프로 48만원/년 · 프리미엄 96만원/년
- **현황**: 유료 100개 학교 미만, 무료 포함 200개 학교, 토스페이먼츠 한도(월 1,000만원) 초과
- **확장**: 상담교사 → 진로교사 → 담임교사로 타겟 확장 (한 학교에서 4개 라이선스 구매 사례)
- **B2G 진입**: 교육부 에듀집 등록, 교육청에서 자체 안내

## 개발 여정

### v1: 실패
- **도구**: Replit (400달러, 3일 작업)
- **실패 원인**: 클라우드 저장 → 민감 정보 유출 우려로 현장 거부, 얼리어답터 요구사항이 대중과 괴리

### v2: PMF 달성
- **도구**: Claude Code (현재 메인)
- **기술 스택**: Electron + SQLite (로컬 데스크탑 앱), 전문 개발자들 반대에도 Claude와 논의해 채택
- **개발 방식**: 브랜치 없음, 테스트코드 없음, 프롬프트 중심, 손으로 QA 후 배포

### Claude Code 활용 루틴
- 커서 → 터미널 전용 Claude Code → Conductor 시도(팀 작업 도구라 맞지 않음) → OpenSpec 시도(오버 엔지니어링) → Claude Skills 최소화로 정착
- "기능 빨리 만들고 손으로 테스트해서 8시 전까지 배포" — 선생님 출근 전 업데이트

## 창업 철학

### 기술 매몰 경계
> "기술에 매몰되지 말라. 엑셀로 템플릿 잘 만들어서 파는 것도 사업이다."

- 화려한 기술보다 고객 문제 해결이 먼저
- 제품에 AI 붙이는 것보다 AI가 실제로 대체하는 일이 무엇인지 파악이 핵심

### 해자(Moat) 전략
- 기능은 한 달 만에 복제 가능 (CRUD 서비스 본질)
- **진짜 해자**: 커뮤니티(1,000명) + 역량 강화 콘텐츠 + 멘토 네트워크
- 위노트 유료 고객 = 커뮤니티 인증 혜택, 상담 역량 강화 자료 접근

### 사명
- 학교 상담교사의 행정 부담 경감 → 아이들 상담 시간 확보
- 기초수급 가정, 자살·자해 위기 아이들의 1차 안전망인 상담교사 지원
- 2년 목표: 5,000개 학교 도입 + 위기 아이들 지원 재단·콘텐츠
