# 화장품창업가이드 QnA ATOZ — 올코스 10부작

대한화장품산업연구원 자료 기반의 화장품 창업 입문 시리즈(2020.8~2021.1). 사업자등록부터 브랜딩·해외 수출까지 전 과정을 10회에 걸쳐 설명.

## 요약

화장품 산업은 약 34.6조원 규모, 연 성장률 16.4%(국내 평균 3% 대비 고성장). 초보 창업자가 자신의 브랜드로 화장품을 만들어 파는 전 과정을 단계별로 안내.

## 전체 흐름

```
창업 준비 → 자금 확보 → 사업자등록 → 제품 기획 → 책임판매업자 자격
→ 상표등록 → 원가분석 → 판매가 책정 → 채널 선택 → 통신판매업 신고
→ 판매 → 피드백 수용 → 브랜딩 → 해외 진출
```

## EP별 핵심 내용

### EP01 — 화장품 창업 어떻게 해요?
- 개인사업자(세금 6~42%) vs 법인사업자: 초기는 개인사업자, 매출 25% 이상 시 법인 전환 권장
- 사업자등록 후 통신판매업 신고 필수

### EP02 — 정부 창업지원
- 기업마당, K-startup에서 지원사업 검색
- 예비창업패키지: 사업자등록 전에도 신청 가능
- 사업계획서 + 피칭이 당락 결정. 예산 소진 전 빠른 신청 필수

### EP03 — 화장품 책임판매업자
- **자신의 브랜드로 판매하려면 반드시 필요**
- 자격: 관련 학과 졸업 OR 업계 2년 이상 경력 OR 이론·실무 능력 입증
- 연 1회 4~6시간 정기교육 필수
- 남의 브랜드 유통만 하면 불필요 / 해외 수출 시 필수

### EP04 — 브랜드 지적재산권
- **OEM**: 처방전을 제공하고 제조사가 생산
- **ODM**: 아이디어·컨셉만 제공하고 제조사가 개발+생산
- 상표등록: 일정 마케팅 후 신뢰도·품질 보증·광고 목적으로 실시
- 아이디어만으로는 지적재산권 보호 불가 — 구체적인 설계·형태화 필요

### EP05 — 제품 기획에서 출시까지
- 제품 컨셉 수립 → 원료·처방 개발 → 용기·패키지 선정 → 품질 검사 → 출시

### EP06 — 판매가 책정
- 원가 = 원료비 + 임가공비 + 패키징비 + 특허료 + 세금 전부 포함
- 타겟층(연령·성별·경제력)에 따라 구매력이 달라짐
- 용기 최소 주문수량: 글라스 3,000개 / 플라스틱 1,000~5,000개 / 튜브 5,000~10,000개
- **프리몰드**(기존 용기 재사용)로 초기 비용 절감 가능
- 채널별 차등 전략: 면세점·홈쇼핑·오픈마켓 수수료가 다름

### EP07 — 플랫폼 선택
- 초기 진입: 진입장벽 낮은 오픈마켓(쿠팡, 11번가) 우선
- 단일 제품 → 소셜커머스 / 시리즈 제품 → 자사몰 + 브랜딩
- 인플루언서 마케팅: 진정성 있는 협업이 핵심 (중국식 물량 공세와 다름)

### EP08 — 전자상거래 실무
- 온라인 판매 3대 필수: 사업자등록 + 통신판매업 신고 + 에스크로
- 수수료: 네이버 약 4% / 오픈마켓 8~30%
- 계약택배로 배송비 절감(2,000원대), 초기엔 편의점 택배 활용도 가능

### EP09 — 브랜딩
- 브랜딩 = 제품의 신뢰도·가치·스토리를 소비자 마음에 심는 것
- 기능 복제는 쉬워도 브랜드는 복제 불가

### EP10 — 강사들의 마지막 당부
- **죽음의 계곡**: 창업 1~2년 자본 부족 위기 — 대부분 여기서 포기
- 매출 증가 시 반드시 재투자, 초기 손실 감수 각오 필요
- 성공 3요소: (1) 명확한 사업 방향성 (2) 중도 포기 금지 (3) 피드백 수용
- 제조사 선택: 규모보다 특정 분야 노하우 있는 소규모 회사 추천
- **해외 우선 전략**: 해외에서 먼저 판매 → 역수입 이미지로 국내 런칭하면 성장 가속

## 주요 용어

| 용어 | 설명 |
|------|------|
| 책임판매업자 | 자기 브랜드 판매의 법적 책임자. 자격 조건 충족 필수 |
| OEM | 처방전 제공, 제조사가 생산 |
| ODM | 아이디어만 제공, 제조사가 개발+생산 |
| 프리몰드 | 기존 규격 용기 재사용으로 초기 비용 절감 |
| 죽음의 계곡 | 창업 1~2년 자금 부족 위기 구간 |
| 에스크로 | 구매자 보호 결제 시스템 |
| 배대지 | 국내→해외 창고 대리 배송 서비스 |
| 아마존 FBA | 아마존 창고에서 직접 배송 처리 |
