# 김시덕 — 위험 지역 & 하락 경고 시리즈

[[wiki/entities/people/김시덕]] 도시문헌학자의 투자 위험 지역, 강남 구조적 한계, 지방 소멸 경고 시리즈.

## 요약

강남은 싱크홀·지반 불안정이라는 구조적 위험이 있으며, 이미 "확장 강남 벨트"로 자산 가치가 분산되고 있다. GTX 단독 호재로 투자한 외곽 지역은 공실 위험이 크다. 지방 소멸은 인구 수보다 일거리 문제다.

## 강남 구조적 한계

- **강남은 계곡 위**: 강남 3구는 역사적으로 계곡 지형 위에 개발 → 싱크홀·지반 침하 위험
- **강남 개발자들이 가장 후회한 것**: 지반 약점을 무시하고 개발한 결과물이 남아있음
- **강남 위상의 구조적 지속**: "전쟁급 충격 없이는 강남 위상 변화 어렵다" → 다만 '확장'으로 희석
- **재건축 시장 호황 종료**: 과거 강남 재건축의 호황 패턴은 돌아오지 않을 것
- **1가구 1주택 정책 이후**: 투자 목적 강남 보유 메리트 감소

## 투자 위험 지역 목록

| 지역 | 위험 요인 |
|------|----------|
| 강남 3구 전역 | 지반 불안정, 싱크홀, 재건축 호황 종료 |
| 반포 (평당 2억원대) | 투자 매력도 대비 과대평가 |
| GTX 역세권 일부 외곽 | 텅 빈 역세권, 생활 인프라 부재 |
| 위례신도시 | 신사선 완성 실패, 교통 기대치 미달 |
| 세종시 전체 | 대통령실·국회 이전 없으면 인구 반토막 가능 |
| 용인 전체 | 반도체 호재 수혜는 삼성 공장 인근 극소 지역만 |
| 청주 동남부 (현도·분평) | SK하이닉스 벨트와 무관한 지역 |

## 지방 소멸 분석

- **인구 수 문제가 아닌 일거리 문제**: 일자리(노동 수요)가 없으면 인구가 있어도 소멸
- **혁신도시 분산 실패**: 여러 곳에 분산 배치하면 모두 실패. 집중화가 필요
- **압축 도시 모델**: 증평군·거창 등 인구 감소 시 군청 중심 15분 생활권으로 전략적 축소
- **귀촌·귀향 인구의 역할**: 지역 산업을 세계 수준으로 마케팅하는 인력이 지역 생존의 열쇠
- **세종시의 딜레마**: 기능 불완전 → 서울 통근 포기하고 정착하는 역설. 완성되면 오히려 서울 1시간권으로 근거리화 → 매력 저하
