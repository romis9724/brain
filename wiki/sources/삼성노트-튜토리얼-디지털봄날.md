# 갤럭시 삼성노트 메모앱 5가지 신기능

"디지털 봄날" 채널의 삼성 갤럭시 노트 앱 실용 튜토리얼. 50대 이상을 주 대상으로 함.
서류 관리·음성 녹음·PDF 처리를 스마트폰 기본 앱으로 해결하는 방법.

## 핵심 기능 5가지

1. **카메라 스캔 → 텍스트 추출**: 종이 서류·안내문을 카메라로 비추면 노란색 T 버튼 → 글자 형태로 삼성노트에 추가 (사진 아닌 텍스트로 저장)

2. **PDF 파일 통합 관리**: 삼성노트 앱 내 더하기 → PDF 메뉴 → 기기에 저장된 건강검진표·연금 서류 등 한 곳에서 관리

3. **PDF 키워드 검색**: 긴 서류에서 점 세 개 → 검색 → 키워드 입력 → 해당 위치로 바로 이동. 다음 위치 순차 이동 가능

4. **화면에 직접 서명**: PDF 열고 툴바에서 색깔·굵기 조절 후 손가락으로 사인 → PDF로 공유 → 카카오톡 전송. 인쇄·다시 촬영 불필요

5. **음성 녹음 + 자동 텍스트 변환**: 진료실 등에서 녹음 → 녹음 완료 후 음파+T 버튼 → 자동 텍스트 변환 → 재생 시 현재 위치 파란색 하이라이트, 원하는 텍스트 터치 → 해당 시점부터 재생

## 추가 팁

- 폴더 정리: 줄 세 개 → 폴더 관리 → 폴더 추가 → 색상 지정 → 메모 이동으로 주제별 정리
- 기존 사진도 갤러리에서 노란 T 버튼으로 텍스트 추출 가능
