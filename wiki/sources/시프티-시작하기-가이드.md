# 시프티(Shiftee) 시작하기 가이드

근태관리·인사관리 SaaS [[wiki/entities/tools/shiftee|시프티]] 공식 헬프센터의 "시작하기" 카테고리 8개 문서(관리자/직원 시작 가이드, 회원가입, 회사 생성, 직장 합류, 모드 전환, 데이터 마이그레이션, FAQ) 모음.

## 요약

시프티는 **최고관리자가 회사를 생성 → 직원이 합류**하는 구조의 클라우드 근태관리 시스템. 웹·모바일 단일 계정으로 회원가입, 회사 세팅(관리 단위·출퇴근 장소·조직/지점·직무·회사 설정), 직원 추가/초대, 출퇴근 기록 시작까지 5단계로 온보딩한다. 기존 HR 솔루션·ERP의 인사·근태 데이터는 엑셀 양식 또는 Open API로 별도 개발 없이 마이그레이션할 수 있다.

## 핵심 포인트

### 관리자 온보딩 5단계
1. **회원가입** — 이메일 본인 인증(3분 내 메일), 네이버/구글 연동 시 인증 불필요. 단일 계정으로 웹·모바일 공용
2. **회사 생성** — 회사 선택 페이지에서 "+ 회사 만들기" (웹/모바일 모두 지원)
3. **회사 세팅**
   - **관리 단위**: 조직(부서/팀) vs 지점(지역별)
   - **출퇴근 장소**: 엑셀 일괄 등록, 좌표/IP/WiFi 기반 인증
   - **조직/지점**: 출퇴근 장소 매핑, 엑셀 일괄 등록
   - **직무**: 실제 직급 무관, 승인권자/비승인권자 2분류 권장
   - **회사 설정**: 권장 재설정 항목 5가지
4. **직원 추가·초대** — 엑셀 일괄 추가, 합류코드 전송, 근로정보(연장·최대근로 규칙) 설정 시 정교한 관리 가능
5. **근태관리 시작**

### 직원 온보딩
1. 회원가입(본인 인증) → 2. 회사 합류 → 3. 출퇴근 기록(근무일정 시작/퇴근 전·지각·초과근무 알림) → 4. 전자결재 요청(근무일정/출퇴근기록/휴가, 잔여 휴가 동시 확인)
- 직원모드 웹 화면: 달력형 근무일정, 기간 내 근로시간·휴가 통계

### 액세스 권한 구조
- 최고관리자 / 관리자 / 직원 모드, 관리자모드↔직원모드 전환 가능

### 데이터 마이그레이션 (도입 핵심)
- 기존 HR 시스템·ERP 데이터를 **엑셀 양식** 또는 **Open API**로 이전, 별도 연동/개발 불필요
- 업로드 단계에서 오류 셀을 붉은색 표시 → 사유 확인 후 수정
- **엑셀 업로드 가능 항목**: 직원, 근로정보, 직무, 조직, 근무일정, 근무일정 유형/템플릿, 휴가 그룹/유형/목록/발생, 출퇴근기록, 출퇴근 장소, 스케줄 패턴, 승인 규칙
- 연차 휴가 마이그레이션: 회계연도 기준 / 입사일 기준 / 맞춤 규칙 모두 지원

### 주요 기능 영역 (헬프센터 카테고리)
- 계정 / 조직·지점 / 직무 / 직원 / 근무일정 / 출퇴근기록 / 휴가 / 전자결재(승인) / 통계·리포트

## 인사이트
- **별도 개발 없는 엑셀/API 마이그레이션**과 모바일 출퇴근 인증(좌표·WiFi)이 중소·소상공인 도입 진입장벽을 낮추는 핵심
- [[wiki/concepts/화장품-창업-가이드|화장품 창업]] 등 오프라인 인력을 운영하는 소규모 사업의 근태·급여 기반 자동화 후보 도구
