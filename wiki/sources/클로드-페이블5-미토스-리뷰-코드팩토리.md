## 요약

[[entities/people/코드팩토리]] 채널이 Anthropic의 신규 모델 [[entities/tools/claude-fable5]](Fable 5, 미토스 클래스 첫 번째 모델)를 Claude Opus 4.6과 직접 비교한 리뷰 영상. Figma 클론·Notion 클론·보안 검사 세 가지 작업을 동일 프롬프트로 양측에 동시 실행해 시간·토큰·결과물 품질을 비교했다.

---

## 핵심 포인트

### 미토스 클래스 모델 계층

- **미토스(Mythos) 클래스**: Anthropic이 새로 도입한 최상위 모델 계층. 계층 안에 여러 모델(객체)이 존재
- **페이블 5 (Fable 5)**: 미토스 클래스 중 현재 가장 낮은 티어. 비유: "장영실급·장보고급 잠수함 클래스 안의 첫 번째 실제 함정"
- **프로젝트 글래스윙(Glasswing)**: 미토스 클래스의 다른 모델. 아직 출시 전, 보완적 기능 개발 중
- 앞으로 더 높은 미토스 클래스 모델들이 추가 출시 예정

### 속도 & 토큰 사용량

| 항목 | 페이블 5 (미토스) | 오퍼스 4.6 |
|------|----------------|-----------|
| Thinking 시간 | 14~25분 | ~5분 |
| Thinking 토큰 | 50,000~100,000 | ~23,000 |
| 총 작업 시간 | 53~58분 | 38~49분 |
| 에이전트 실행 방식 | 서브에이전트 5개+ 자동 생성 | 단독 실행 |

- 4개 세션 동시 실행 시 컨텍스트 사용량 0%→36% 증가
- 울트라 코드(ultracode) 미사용 — 사용 시 $200 플랜 전량 소모 가능성

### 결과물 품질 비교

**Figma 클론**
- 둘 다 드래그 도형, 색상 변경, 투명도, 화살표, 스티키 노트 구현
- 페이블 5: 스티키 노트 3D 그림자·기울기 등 시각적 완성도 미세하게 높음
- 페이블 5는 밝은(light) 테마 선호 / 오퍼스는 다크 테마 선호

**Notion 클론**
- 슬래시 커맨드, 헤딩, 데이터베이스, 태그(@멘션) 모두 구현
- 드래그 앤 드롭 위치 정확도는 양측 모두 QA 미흡
- 미토스: 한국어 인터페이스 기본 생성 / 오퍼스: 영어 기본

**보안 검사**
- 오퍼스: 11분, 7건 발견 (크리티컬 없음, 즉시 악용 가능 취약점 없음)
- 페이블 5: 에이전트 5개 병렬 실행, 23건 발견 (더 낮은 등급까지 상세 발굴)

### 가격 & 사용 권장

- $200/월 플랜에서 **2026년 6월 말까지** 페이블 5 포함 → 이후 Extra Usage로 전환
- 화자 권장 사용법:
  - 일반 바이브 코딩 → 오퍼스로도 충분
  - 중요 릴리스, 크리티컬 버그픽스 → 페이블 5 사용
