# 코인 자동매매봇 (Automated Crypto Trading Bot)

사전 정의된 규칙·알고리즘에 따라 인간 개입 없이 자동으로 매수·매도 주문을 실행하는 프로그램. 가상자산 시장의 24시간 운영 특성상 자동화 수요가 특히 높다.

## 자동매매의 장점

- **감정 배제**: 공포·탐욕 없이 규칙대로 실행
- **24/7 운영**: 수면 중에도 시장 대응 가능
- **속도**: 인간 반응 속도의 한계 초월 (스캘핑에 특히 유리)
- **백테스팅**: 과거 데이터로 전략 검증 후 실전 투입
- **다중 포지션 동시 관리**: 여러 코인 동시 모니터링

## 주요 구현 방법

### 코딩 기반
- **파이썬(Python)**: 가장 널리 사용. ccxt 라이브러리로 거래소 API 연동
- **트레이딩뷰 Pine Script**: 전략 작성 후 웹훅으로 주문 자동화
- **챗GPT 활용**: 30분 내 자동매매 전략 코딩 가이드 등장

### 노코드 플랫폼
- 코딩 없이 조건 설정만으로 봇 구성
- 드래그앤드롭 UI로 전략 로직 구성

### 메타트레이더(MT4/MT5) 연동
- 해외선물·코인 자동매매에 활용
- EA(Expert Advisor) 방식으로 전략 구현

## 주요 전략 유형

| 전략 | 설명 |
|------|------|
| 이동평균 교차 | 단기 MA가 장기 MA를 돌파할 때 매수·매도 |
| 볼린저밴드 리버전 | 밴드 하단 터치 매수, 상단 매도 |
| 마틴게일 | 손실 시 베팅 금액 2배로 복구 시도 (위험도 매우 높음) |
| 변동성 돌파 | 전일 변동성의 k배 상승 시 매수 |
| 그리드 트레이딩 | 일정 구간마다 분할 매수·매도 반복 |
| 피보나치 기반 | 주요 피보나치 레벨에서 매매 조건 설정 |

## 백테스팅과 실전의 괴리

- 과거 데이터 과적합(overfitting) 위험
- 슬리피지·수수료를 반영해야 현실적 결과 도출
- 시장 국면(상승장/하락장/횡보) 변화 시 성과 급변 가능
- 마틴게일 전략: 장기적으로 계좌 소진 가능성 매우 높음

## 리스크

- **블랙스완 이벤트**: 예기치 못한 급락 시 자동 손절 미작동 가능
- **API 보안**: 거래소 API 키 유출 시 자산 탈취 위험
- **버그**: 코드 오류로 의도치 않은 대량 주문 발생 가능
- **의존성 과잉**: 봇에만 의존, 시장 본질 이해 부족
