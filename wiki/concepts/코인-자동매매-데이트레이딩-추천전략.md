# 코인 자동매매 데이트레이딩 추천전략

247개 코인매매전략 영상 ingest 및 자동매매봇 전략 wiki를 종합해 도출한 실전 자동매매 구현용 전략 가이드.
복잡한 시스템보다 **단순한 규칙의 철저한 반복**이 장기 생존의 핵심이라는 공통 결론을 기반으로 정리됨.

---

## 핵심 전제

- 지표 1~2개 조합 + 명확한 진입·청산 기준의 일관된 실행이 핵심
- 백테스팅 시 슬리피지·수수료·MDD를 반영해야 현실적 결과 도출
- 당일 청산 원칙 유지 — 오버나잇 리스크 제거

---

## 추천 전략 3종

### 전략 1 — 이동평균 교차 + RSI 교차검증 (15분봉)

추세 방향을 EMA 크로스로 포착하고, RSI로 과매수·과매도 구간을 필터링하는 가장 기본적인 자동매매 전략.

| 조건 | 내용 |
|------|------|
| 매수 진입 | 단기 EMA × 장기 EMA 골든크로스 + RSI 30~50 구간 |
| 매도 청산 | 데드크로스 OR RSI 70 초과 |
| 교차검증 | MACD 골든크로스 + 볼린저밴드 하단 이탈 여부 |
| 거래량 필터 | 거래량 수반 여부 필수 확인 (없으면 가짜 신호) |
| 타임프레임 | 15분봉 기본 |

적합 시장: 방향성 있는 추세 구간

### 전략 2 — 볼린저밴드 + RSI 평균회귀

변동성 밴드와 과매도 지표를 결합해 반등 타점을 포착하는 전략.

| 조건 | 내용 |
|------|------|
| 매수 진입 | 볼린저밴드 하단 터치 + RSI 30 이하 동시 충족 |
| 매도 청산 | 볼린저밴드 중심선(20MA) 회귀 OR RSI 70 이상 |
| 추가 활용 | 밴드 수축(스퀴즈) 감지 → 브레이크아웃 직전 신호 |

적합 시장: 횡보·박스권 구간

### 전략 3 — VWAP 기반 단타 (1~5분봉)

세력 평단가(VWAP)를 지지·저항선으로 활용하는 단기 매매 전략. 시장 개장 직후 구간에 특히 유효.

| 조건 | 내용 |
|------|------|
| 매수 진입 | 가격이 VWAP 위로 복귀 시점 + 이동평균 지지 확인 |
| 매도 청산 | VWAP 아래 이탈 OR 목표 수익 달성 |
| 타임프레임 | 1~5분봉 |

적합 시장: 유동성 높은 피크타임, 시초가 직후

## 리스크 관리 원칙

| 항목 | 권장값 |
|------|--------|
| 손절(Stop-Loss) | 진입가 대비 1.5~3% |
| 1회 거래 리스크 | 자본의 1~2% |
| MDD 상한 | 사전 설정 필수 |
| 마틴게일 전략 | **절대 금지** — 블랙스완 발생 시 전액 청산 필연 |

---

## 구현 우선순위

1. **거래소 API 연동**: ccxt 라이브러리 (바이낸스/업비트)
2. **지표 계산**: TA-Lib 또는 pandas-ta
3. **백테스팅**: Backtrader 또는 VectorBT
4. **API 보안**: 키 환경변수 분리, IP 화이트리스트 설정
5. **페이퍼 트레이딩**: 실매매 전 최소 2주 시뮬레이션 운용

---

## 피해야 할 것

- **마틴게일 전략**: 손실 시 베팅 2배 복구 구조 — 장기 계좌 소진 필연
- **지표 과적합 백테스팅**: 과거 최적화 파라미터는 미래를 보장하지 않음
- **슬리피지·수수료 미반영 시뮬레이션**: 실전 수익률과 큰 괴리 발생
- **시장 국면 미구분**: 한 전략이 모든 국면(상승·하락·횡보)에서 통하지 않음
