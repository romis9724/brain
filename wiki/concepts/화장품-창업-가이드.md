# 화장품 창업 가이드

자신의 브랜드로 화장품을 만들어 파는 1인·소규모 창업의 전 과정. 법적 요건부터 제품 기획, 가격 책정, 채널 전략, 해외 진출까지.

## 시작 전 필수 체크

### 사업자 형태
- **개인사업자**: 초기 권장. 세율 6~42%, 절차 간단
- **법인사업자**: 매출의 25% 이상이 세금으로 나갈 때 전환 권장

### 책임판매업자 자격
자신의 브랜드로 판매하려면 반드시 필요:
- 관련 학과 졸업 OR 업계 2년 이상 경력 OR 이론·실무 능력 입증
- 연 1회 4~6시간 정기교육 의무
- 해외 수출 시에도 필수, 타 브랜드 유통만 하면 불필요

### 필수 행정 절차
1. 사업자등록 (개인/법인 선택)
2. 책임판매업 등록
3. 통신판매업 신고 (온라인 판매 시)
4. 에스크로 가입 (각 마켓에서 자동 처리)

## 제품 개발: OEM vs ODM

| 구분 | OEM | ODM |
|------|-----|-----|
| 내가 하는 것 | 처방전 제공 | 아이디어·컨셉 제공 |
| 제조사가 하는 것 | 생산만 | 개발 + 생산 |
| 적합한 경우 | 독자 레시피 있을 때 | 초보·소규모 창업 |

- **프리몰드** 활용: 기존 규격 용기 재사용 → 초기 투자 비용 대폭 절감
- 용기 최소 주문수량: 글라스 3,000개 / 플라스틱 1,000~5,000개 / 튜브 5,000~10,000개

## 가격 책정 원칙

원가 = 원료비 + 임가공비 + 패키징비 + 특허료 + 세금 모두 포함  
타겟(연령·성별·소득)에 따른 구매력 차이 반드시 고려  
채널별 수수료 차등: 네이버 ~4% / 오픈마켓 8~30% / 홈쇼핑·면세점 별도

## 판매 채널 전략

| 단계 | 전략 |
|------|------|
| 초기 | 오픈마켓(쿠팡, 11번가) — 진입장벽 최소 |
| 단일 제품 | 소셜커머스 집중 |
| 시리즈 제품 | 자사몰 + 브랜딩 구축 |
| 성장기 | 인플루언서 협업 (진정성 중심) |
| 글로벌 | 아마존 FBA, 배대지 활용 |

## 브랜딩의 중요성

> "기능은 복제되지만 브랜드는 복제할 수 없다."

브랜딩 = 제품의 신뢰도·가치·스토리를 소비자 마음에 심는 것  
상표등록은 어느 정도 마케팅 성과 확인 후 실시  
아이디어만으로는 지적재산권 보호 불가 — 구체적 설계·형태화 필요

## 자금 조달

- **정부 지원**: 기업마당(www.bizinfo.go.kr), K-startup(www.k-startup.go.kr)
- **예비창업패키지**: 사업자등록 전에도 신청 가능
- 사업계획서 + 피칭 능력이 당락 결정

## 생존 원칙 (죽음의 계곡 극복)

- **죽음의 계곡**: 창업 1~2년 자금 부족 위기 — 대부분 여기서 포기
- 매출 증가 시 반드시 재투자, 초기 손실 감수 각오
- 성공 3요소: 명확한 방향성 + 중도 포기 금지 + 피드백 수용

## 해외 진출 전략

- **해외 우선 전략**: 해외(아마존 등)에서 먼저 성공 → 역수입 이미지로 국내 런칭 = 성장 가속
- 아마존 FBA: 아마존 창고에서 보관·배송 대행, 글로벌 진출 가장 현실적인 루트
- 배대지 선택 신중히 (업체 신뢰도 확인 필수)
