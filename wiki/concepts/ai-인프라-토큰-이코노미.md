# AI 인프라 & 토큰 이코노미

토큰 이코노미 관점에서 AI 데이터센터 공급 구조와 투자 기회를 분석하는 프레임. 김지현 SK 부사장이 제시한 4단계 병목 구조와 5단 케이크 투자 지도가 핵심.

## 토큰 = AI 인프라의 기본 단위

AI 연산은 토큰을 생산하는 과정이다. 데이터센터는 "토큰을 얼마나 빠르고, 싸고, 많이 생산할 수 있는가"로 평가된다.

**3대 토큰 생산 지표**:
| 지표 | 의미 | 관련 기술 |
|------|------|----------|
| 초당 토큰 수 (TPS) | 속도 = GPU 가동률 | 고성능 GPU, 메모리 대역폭, 아이들 최소화 |
| 와트당 토큰 수 (TOW) | 에너지 효율 | 냉각(수냉 전환), 실리콘 포토닉스, 저전력 칩 |
| 100만 토큰 원가 | 비용 효율 | GPU 감가상각, 가동률, 저가 MPU 활용 |

## 4단계 병목 순서

```
1차 반도체 → 2차 전력/냉각 → 3차 네트워크 → 4차 데이터
```

### 1차: 반도체 병목 (완료, 현재 원가 절감 단계)
- GPU(엔비디아), HBM(SK하이닉스·삼성전자·마이크론)이 공급 부족
- 현재 전환: 고성능 GPU→MPU(Intel/AMD/퀄컴/리벨리온 등), HBM→LPDDR
- 빅테크(메타·MS·아마존·구글)가 자체 MPU 개발 → 엔비디아 의존도 감소 시도

### 2차: 전력/냉각 병목 (현재 진행 중)
- 데이터센터 전력의 30~35%가 냉각에 사용
- 공냉→수냉 전환으로 에너지 효율 향상
- 전력 설비, 냉각 솔루션 기업 수혜

### 3차: 네트워크 병목 (임박)
- 서버 내부 구리선 → 실리콘 포토닉스(광케이블)
  - 열 발생 없음, 손실 최소화, 고대역폭
  - 엔비디아가 각 20억 달러+ 투자
  - 광케이블 전문 기업 3년간 ~1,000% 성장
- **AI RAN**: 기지국에 소형 데이터센터 → 디바이스↔기지국↔클라우드 하이브리드
- 온디바이스 AI + 엣지 처리 = 네트워크 트래픽 폭증

### 4차: 데이터 병목 (1~2년 후)
- 공개 인터넷 데이터 학습 거의 완료 → AI 모델 개선에 미디지털화 데이터 필요
- 인도 '핸드팜': 작업자 머리에 카메라 → 작업 데이터 수집 → 휴머노이드 로봇 학습
- **스마트 글라스**: 건물·식당·가정 등 일상 공간 데이터 수집 통로
- 테슬라 자율주행 데이터 수집 모델의 확장판

## 메모리 기업의 꽃놀이패

SK하이닉스·삼성전자·마이크론은 어떤 시나리오에서도 유리:

| 시나리오 | 필요한 메모리 |
|----------|-------------|
| 고성능 GPU 지속 | HBM |
| 저가 MPU 전환 | LPDDR, SRAM |
| 온디바이스 AI | 소형 LPDDR |
| 엣지 데이터센터 | DRAM, 플래시 |

## 5단 케이크 투자 지도

```
5 — 애플리케이션·에이전트 (실제 사용자 서비스)
4 — 에이전트 플랫폼·AI 솔루션 (NEMO, AWS Bedrock 등)
3 — 모델 레이어 (OpenAI, Anthropic, Google Gemini 등)
2 — 클라우드 인프라 (AWS, Azure, GCP)
1 — 물리 데이터센터 (GPU, 메모리, 전력, 네트워크)
```

**구글 = AI 풀스택**: 1~5 레이어 전체 담당. TPU(자체 MPU) + 광케이블 + 유튜브/Gmail 데이터 + 스마트 글라스 (4차 병목까지 대비)

**엔비디아 = 레이어 1 지배 후 확장**: GPU→CPU(Versa)→네트워크→에이전트 플랫폼(NEMO Curator)으로 영역 확장

## 경량 데이터센터 (MDC/hiDC)

- 추론·에이전트용 소규모 처리 (100MW~5MW)
- 모듈러 컨테이너형 → 빠른 배포
- 공항·공장·건물 인근 엣지 AI 처리
- 대형 파운데이션 모델 학습 인프라와 구조 다름 → 특화 솔루션 기업 수혜

## 투자 시사점

1. **메모리**: 어떤 칩이 이기든 SK하이닉스·삼성전자·마이크론 수혜
2. **광케이블**: 3차 병목 도래 전 선점 기회 (실리콘 포토닉스 전문사)
3. **전력 설비**: 에너지 효율화 수요 지속
4. **데이터 수집**: 4차 병목 대비 → 스마트 글라스, 산업 IoT, 영상 데이터 기업
